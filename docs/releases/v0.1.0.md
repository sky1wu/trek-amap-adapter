# v0.1.0

首个 TREK 高德 Places 适配器版本，提供文本搜索、自动补全和地点详情，无需修改 TREK 源码或数据库。

- 支持稳定 `amap_` 地点 ID、WGS-84 / GCJ-02 双向转换，覆盖大陆及港澳台。
- 提供缓存、超时与并发限制、可选适配器鉴权和安全日志。
- 公开 GHCR 镜像支持 `linux/amd64`、`linux/arm64`，部署示例固定使用 `v0.1.0`。
- 161 项自动测试及双架构容器检查通过。
- TREK UI 人工验收已完成，西安、香港实测通过（2026-09-12，项目维护者确认）。

```sh
docker pull ghcr.io/sky1wu/trek-amap-adapter:v0.1.0
docker compose -f docker-compose.example.yml pull
docker compose -f docker-compose.example.yml up -d --no-build
```

在本地 `.env` 配置 `AMAP_KEY`；若已有 `ADAPTER_IMAGE=...:latest`，请改为 `ghcr.io/sky1wu/trek-amap-adapter:v0.1.0`。原始任务书与 `.env` 不纳入发布。

高德路线规划作为 Phase 2 在本次发版之后独立推进，不包含在 v0.1.0 中。
