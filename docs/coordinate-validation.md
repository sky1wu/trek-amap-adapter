离线测试日期：2026-09-12；真实 API 验证日期：2026-09-12。记录分为离线算法测试和真实 POI/底图验收。

转换范围依据[高德官方说明](https://lbs.amap.com/faq/advisory/others/39840/)：大陆、香港、澳门、台湾返回 GCJ-02，海外返回 WGS-84。此前将港澳台原样返回的实现及断言已修正。

反算最多迭代 30 次，偏差阈值 1e-9 度；表中误差基于未舍入值，以角度差乘 111320 估算上界。除北京正向固定向量外，香港、澳门、台北均有固定正反向数值回归，防止只检查 round-trip 而漏掉不转换的实现。测试还覆盖海南、香港大屿山与机场、澳门氹仔与路氹、高雄、澎湖、金门；东京、首尔、河内、加德满都、乌兰巴托、海参崴、石垣岛、马尼拉、台湾以北远海、伦敦和 0,0 均保持不变。

接口回归模拟高德返回香港、澳门、台北 GCJ-02 坐标，分别验证 Text Search 与 Place Details 返回 WGS-84，自动补全 ID 可解析到相同详情，以及搜索和自动补全的 bias 使用 GCJ-02。预期值为固定数值，不在断言中调用被测转换函数；这些仍是离线测试，不能代替港澳台真实 POI 的底图验收。

这些极小残差只说明数值反算一致，**不代表亚毫米测绘精度**。GCJ 算法是近似模型，地图底图、POI 锚点、建筑入口和地理边界还会造成误差。实际验收结论见下节。

后续新增地点的人工验收步骤：

1. 在 TREK 的 OpenFreeMap 底图打开记录的 WGS-84 坐标，与建筑/场地位置比较；同时打开原 GCJ-02 坐标作偏移对照。
2. 区分入口与建筑中心的正常 POI 差异，以及成片方向一致的几百米 GCJ 偏移；保存截图、地图缩放级别和检查日期。
3. 检查十个目标的中文名称、地址、自动补全，以及点击提示后详情。
4. 保存地点，关闭后重开；重启 TREK 与 Adapter 后再次打开。
5. 更新本文件真实坐标、误差判断和结果。不要用离线控制点覆盖这些空白。

## 转换范围限制

使用同一 Natural Earth 1:10m 版本的 CHN、HKG、MAC、TWN 几何作运行范围判断，包含海南及数据内的离岛。数据来源、提取规则和授权见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。这些陆地轮廓有比例尺概化、海岸线时效和小岛遗漏，不能直接等同于高德的坐标适用范围。

香港、澳门使用各自全部几何的包围范围，覆盖港口水域和香港机场等填海区；港澳台范围增加 1 km 近岸容差，以覆盖概化岸线和 GCJ 偏移。台湾保留逐岛多边形及近岸容差，大陆继续使用未扩张的多边形，以免把邻国坐标纳入转换。1 km 是本服务的工程容差，不是高德公布的精确边界；远海、遗漏小岛、新填海地区仍需按实际 POI 验证。

边界附近 GCJ 偏移本身可能跨过多边形，故范围判断无法做到测绘级精确。反算迭代固定首次判断，避免迭代过程反复切换范围；仍不能保证边界两侧的 round-trip。未来如实测发现此类 POI，应在有证据的情况下结合高德行政区信息细化判定。
